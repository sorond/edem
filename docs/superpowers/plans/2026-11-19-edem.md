# Эдем Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Построить сайт «Эдем» для учёта казны одной фракции: куратор видит казну и задания, подаёт рапорты и запросы выплат; Эдем управляет всем через админку.

**Architecture:** Статический SPA на GitHub Pages без сборки, Supabase как база/авторизация/хранилище, GitHub Actions для ежедневного начисления и бэкапа. Вся экономика считается в чистых функциях и в SQL-RPC; админка меняет настройки через Supabase.

**Tech Stack:** HTML, CSS, ES modules, Supabase JS (CDN), Vitest, Supabase Postgres/Auth/Storage, GitHub Actions, Deno Edge Function.

**Spec:** `docs/superpowers/specs/2026-11-19-edem-design.md`

- [ ] **Step 6: Написать `002_rpcs.sql`**

Все RPC — `security definer`, `set search_path = public`.

`current_tax_rate()`:
- читает `base_tax`, `min_tax`, `max_tax`;
- summation `shift` из `tax_events`, где `now() between starts_at and ends_at`;
- `greatest(min_tax, least(max_tax, base + sum))`.

`run_daily_payout()`:
- `v_today := (now() at time zone 'Europe/Moscow')::date`;
- если строка есть в `payout_days` — вернуть `jsonb_build_object('skipped', true)`;
- `v_bonus := coalesce(sum(bonus_percent), 0)` из tasks со `status='completed'` и `bonus_active_until >= v_today`;
- `v_gross := base_payout * (1 + v_bonus / 100)`;
- `v_tax := current_tax_rate()`;
- `v_net := v_gross * (1 - v_tax / 100)`;
- вызвать логику потолка: `v_balance := least(cap, balance + v_net)`, `v_burned := greatest(0, balance + v_net - cap)`;
- обновить `treasury`, вставить `transactions` тип `daily_payout` с `tax_amount = v_gross - v_net`, `balance_after = v_balance`, вставить `payout_days`, `audit_log`;
- пометить просроченные активные еженедельные задания как `failed`, создать `tax_events` с `source='task_penalty'`, `shift=penalty_shift`, `ends_at=now()+penalty_days`;
- вернуть jsonb с `gross`, `taxRate`, `net`, `burned`, `balance`.

`review_report()`:
- проверить `role = 'admin'`, иначе `raise exception 'permission denied'`;
- если `p_decision='approved'`:
  - `v_tariff := tariff_external/internal`, умножить на `task_tariff_percent/100`, если `task_id is not null`;
  - `v_net := v_tariff * (1 - current_tax_rate()/100)`;
  - кредитовать казну с учётом потолка, вставить transaction `report_tariff`;
  - обновить рапорт `status='approved'`;
  - посчитать `approved_count` по заданию; если ≥ `target_count` и задание ещё active — установить `status='completed'`, `completed_at=now()`, начислить `reward_gross` через ту же налоговую функцию, если `kind='weekly'` или `has_bonus` — `bonus_active_until = current_date + 7`;
  - записать `audit_log`.
- если `p_decision='rejected'` — только статус, комментарий, audit_log.

`request_withdrawal()`:
- проверить role curator;
- посчитать `tax_rate=current_tax_rate()`, `tax_amount`, `amount_net`;
- вставить withdrawal, вернуть id.

`review_withdrawal()`:
- только admin;
- при approve: `update treasury set balance = balance - amount_gross`, вставить transaction тип `withdrawal` с отрицательным `amount`, `tax_amount`, `balance_after`;
- статус, комментарий, audit_log.

`adjust_treasury()`:
- только admin;
- `update treasury set balance = balance + p_amount`;
- вставить transaction `manual_edit`, `comment = p_comment`, `tax_amount = 0`;
- audit_log.

`create_task()` / `create_tax_event()` / `update_settings()` / `archive_task()`:
- только admin; вставить или обновить запись и audit_log.

`create_report()`:
- curator или admin; вставить рапорт со статусом `pending`, вернуть id.

`get_settings()` / `get_treasury()` — для фронта.

```ts
import { createClient } from 'https://esm.sh/@supabase/supabase-js@2'

Deno.serve(async (req) => {
  const auth = req.headers.get('Authorization')
  if (auth !== `Bearer ${Deno.env.get('DAILY_PAYOUT_SECRET')}`) {
    return new Response('unauthorized', { status: 401 })
  }
  const supabase = createClient(
    Deno.env.get('SUPABASE_URL')!,
    Deno.env.get('SUPABASE_SERVICE_ROLE_KEY')!
  )
  const { data, error } = await supabase.rpc('run_daily_payout')
  if (error) return new Response(error.message, { status: 500 })
  return Response.json(data)
})
```
